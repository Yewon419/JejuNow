- 서비스 개요(초안, 300자 안팎):

  > 제주 관광지 804곳의 시간대별 혼잡도를 예측해 "지금 어디가 한적한가"를 알려주고, 가려던 곳이 붐비면 같은 유형의 한적한 대안을 추천하는 서비스입니다. 한국관광공사 TourAPI로 관광지 정보를, 한국관광 데이터랩의 8년치 인기관광지 수요 통계를 학습 데이터로 사용해 LightGBM 모델이 월별 수요를 예측하고, 이를 시간대 방문 패턴과 결합해 4단계 혼잡도로 보여줍니다. 지도·일정 시뮬레이션·자동 일정(오토플랜)·경로 안내까지 한 앱에서 이어지며, 회원가입 없이 바로 쓸 수 있습니다.

## 5. 사람 단계 (대표님)

1. **기능설명서 양식 zip 다운로드**(위 Drive 링크) → 압축 해제해 `docs/contest/`에 두면 초안을 양식에 옮겨 PDF까지 만든다.
2. **콘텐츠랩 로그인 → 접수확인에서 팀명·팀원·기존 입력값 캡처**. 팀원 전원 회원가입 여부 확인.
3. **결정 ③ TourAPI 활용 방식**: (a) 현재 주간 배치 그대로 두고 기능설명서에 "주간 동기화 + 상세 보강" 구조로 솔직히 기술, (b) tourapi@knto.or.kr 에 로컬 DB 방식 신청서 문의, (c) 사용자 화면에 실시간 TourAPI 호출 1개 추가(예: 상세 페이지 진입 시 `detailCommon2` 라이브 조회, Vercel 함수 경유). (c)는 코드 변경이라 승인 후 착수.
4. **운영계정 신청**(선택·권장): data.go.kr 로그인 필요.
5. **App Store 승인 오면 출시 버튼** → `apps.apple.com/kr/app/id6792661866` 열리는지 확인 → 폼에 앱 링크 입력. 9/21 16:00까지 승인 안 나면 유형 = 웹으로 제출.
6. **UptimeRobot 모니터 상태 확인**(Render 슬립 방지).
7. 제출 후 완료 메일(콘텐츠랩 발송) 보관.
